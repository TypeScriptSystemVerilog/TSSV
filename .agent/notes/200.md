  - reloaded runs in simulation in this PR;

  - SliceOrder is the only example, with lfsr and phases fixed on;
  - a LoadBus framework test;
  - the template is in `doc/templates/`;
  - a configuration is a JSON file with an explicit schema that names neither the DUT nor the
    testbench;
  - output goes to `sv-examples/tb/<DUT>/<testbench>/`, and the generator itself has no name.
- **Mine, not the user's:**
  - Each build folder keeps its configuration as `<cfg>.json`, not `configuration.json`.
  - Numbers in `parameters` must be safe integers.
  - `depths` may be `{}`.
  - A testcase with 0 records for a preloaded injector is refused by RecordInjector itself.
  - `regression.txt` is whitespace-separated, like `configs.txt`, so no path may hold whitespace.
  - The example TB spec is under `doc/framework/examples/`, because StreamSlice is test code.

## Dead ends
- **SimTop's loader declared after the reset block.** Its `loaded` and `testcase` were used
  before they were declared, so the loader is now emitted first.
- **A seed's top nibble changed in an expected file** still passes, because the payload is the
  Lfsr's low 32 bits. Break a low digit instead.
- **A loader that writes every memory at i + 1** passes: the stimulus and expected records shift
  together. Break one memory only.
- **LoadBus sources picked at random** overflowed an 8-deep source memory. They are now dealt in
  turn, then shuffled.
- **`rm -rf` together with a heredoc in one Bash call** is refused by the safety check. Edit with
  the Edit tool, and keep `rm` in a command of its own.
