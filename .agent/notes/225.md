Decisions taken with Tom in the planning session (also posted as an issue comment):
- Each table memory keeps its own count slot in `records`. The checker's window compares
  `row < records`, and the load-port contract doesn't change.
- One row count per harness: every `table` memory must hold the same count. A harness with two
  tables of different lengths is refused until one needs it.
