## Assumptions
- **The user's decisions, 2026-11-04.** They are in the issue body.
  - Ports `clk_<d>` and `rst_b_<d>`; a harness without domains keeps `clk` and `rst_b`.
  - `releaseAfter` per domain; domains without it are released independently.
  - A domain with `releaseAfter` counts its `resetCycles` from time 0, like every domain, and is
    released at its first falling edge once both those cycles are done and the other domain is
    released (the user's review, 2026-11-04). It used to wait for the other's release before
    counting, which made `wr` wait until 100 instead of 60.
  - An explicit `reportDomain`, required with two or more domains.
- **Mine, not the user's:**
  - `period` is an even integer, so a half period is a whole number of time units.
  - `phase` delays every edge; phase 0 puts the first rising edge at period / 2, like the old
    clock.
  - `released_<d>` is set with `<=`, so a domain waiting for it is released at a strictly later
    falling edge even when both clocks fall in the same time step. Verilator 5.052 orders a
    blocking `=` the same way, but the SV standard doesn't guarantee it.
  - One `resetCycles` for every domain (SimTop's parameter).
- **The single-domain SV is byte-identical** because SimTop keeps the old body for a harness
  without domains, and the bindings keep their order (`clk`, `rst_b`, `done`, `fail`).

## Dead ends
- **Binding `done` and `fail` before the clocks** reordered the harness instance's ports and
  changed every existing testbench's SV. Bind the clock pairs first.
- **The injector's `done` straight into a CDCSynchronizer.** It's a compare of a counter, not a
  flop, and a synchronizer needs a flop at its input. Register it in `wr` first.
- **Leaving the AFIFO's fill counts unbound.** `-Wall` reports a missing pin, and an unread net is
  UNUSEDSIGNAL. Hence the waiver.
- **A LINT-3 justification only in TypeScript.** `sv-scans.mjs` wants an SV `//` comment on the
  `lint_off` line or the line before it.
- **Template literals with ternaries spanning lines** fail ESLint's `multiline-ternary`. SimTop's
  `domainsBody()` builds an array of lines instead.
