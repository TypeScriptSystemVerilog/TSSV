  in simulation (checked for `add_tb` with a Verilator `--binary --timing` wrapper). #148's AC
  asks only for the same expected values, so this is left for a follow-up issue, not filed yet.

  (README "Linting through the top"). `test_importParse.ts` relies on that.

## Dead ends

- A size cast (`6'(in)`) does not mark the dropped bits used; Verilator still reports
  UNUSEDSIGNAL. Slice, and have the failure messages print the full input instead.
- `a + b - 16'((c / d) * e)` still reports WIDTHEXPAND on the division; cast `c / d` itself.
- Waivers in a `.vlt` match the path as Verilator sees it: lint from the repo root, not from
  inside the output folder, or `-file "*/<dir>/..."` patterns don't match.
