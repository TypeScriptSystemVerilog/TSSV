## Dead ends
- **Reading Verilator's `Example path` for the closing assign's line** (the issue's wording).
  On 5.052 a loop inside the module listed wrapper lines, because the module's port is merged
  into the wrapper's net. A loop through a vector's closing assign named the net's declaration
  line, not the assign's. So the check compares with the open wrapper instead (issue comment
  6634921654).
- **Telling a module's own loop from a contract's loop.** When the contract's path runs through
  the module's own loop, the open and closed wrappers give the same `UNOPTFLAT`. So such a module
  is "not checked".
- **`split_var`** isn't needed: closing one bit was exact for a plain assign, an `always_comb`
  with an `if`, and a bit that depends on another input bit.
- **An internal loop made of `x = y ^ in; y = x`** constant-folds once closed, so it shows no
  loop. ReadyPaths' `internalLoop` uses `&&` and `||`.
