## Assumptions
- Verilator checks an interface signal's UNDRIVEN/UNUSEDSIGNAL across all instances of the
  interface, not per instance. That's why the undriven `Targ*.WUSER` and the AXI3 `Init*.ACLK`
  outputs raise no warning. This is inferred from lint output, not from Verilator's docs.
- `posix.relative()` filelist paths work because the tests run from the repo root
  (`runAllTests.sh` changes into it).

## Dead ends
- Requiring every SV port in the XML's `<model><ports>`: the AXI sample's model has no
  `noc_arstn`, so the build threw. The check now skips a port the model doesn't list.
- Tying every undriven bus output to 0: on the AXI sample this would drive `Init*.ACLK`,
  `ACLKEN` and `ARESETn`, because the AMBA3 `AXI` class flips them to outputs on `inward`.
  Filed as #174 instead.
- In the width-mismatch self-check, a regex over the whole XML matched `Init0_Ar_Len` in the
  port maps first and widened the wrong port (`Init1_Ar_Qos`). It must start at
  `<spirit:model>`.
