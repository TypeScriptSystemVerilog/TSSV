## Assumptions

- The SV guide's LINT-3 allows a waiver around a local "sink" signal that reads inputs a design
  ignores on purpose. The guide's own LINT-3 example has this form. A reviewer may prefer
  another way; both waivers are made by `ignoreInputs()` in `FIR.ts`.
- `RegisterBlock` reading a negative coefficient back zero-extended is its intended behavior for
  now. The spec states it, and `tb_FIR.sv` checks it. If `RegisterBlock` changes to sign-extend,
  `read_coeff` in `tb_FIR.sv` and the spec's Register Map need updating.

## Dead ends

- Sizing the accumulator from the reset coefficients: it wraps once other coefficients are
  written. The decision on #152 was a parameter that defaults to the full width.
- A design-specific `.vlt` waiver file for the ignored inputs: `check:generated-sv` passes only
  the common waivers, so it wouldn't clear the baseline.
- Building `tb_FIR` with `run_configs` without the common waivers fails: the plain `+` of the sum
  raises `WIDTHEXPAND`, which only the common waivers cover. The FIR builds pass them.
