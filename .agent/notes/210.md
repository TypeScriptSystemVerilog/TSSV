## Assumptions
- A1: `MAXIMAL_LENGTH[102]` replaces XAPP052's `102,101,36,35` (not primitive: factors of degree
  3, 34 and 65, confirmed with sympy) with x^102 + x^101 + x^26 + x^25 + 1, the only primitive
  polynomial of that shape (found by search). The test proves it primitive.
- A2: the PRBS polynomials (O.150's PRBS9–31, and PRBS7, not in O.150) come from a secondary
  source (a vendor app note found by search); the normative O.150 text wasn't read. The test
  proves each primitive, which is all the library claims.
- A3: Koopman's hex is the toggle mask of his right-shift Galois loop (his page:
  `if (i & 1) i = (i >> 1) ^ feed`), so bit i is x^(i+1). The test runs Wikipedia's Galois
  example with 0xB400, the same form; no Koopman table entry was run.

## Dead ends
- An advance equal to the payload width can share a factor with 2^width − 1 (24 bits on 64:
  gcd 3), which LFSR refuses. `payloadLfsr()` rounds the advance up to a power of 2 instead.
- `tssv/lib/modules/LFSR/mersenneFactors` doesn't resolve in Node (the exports array doesn't
  fall back), so `index.ts` re-exports it.
- A break that leaves `cur` partly unused fails `check-harness` lint before `tb_LFSR` runs: build
  and run `tb_LFSR` alone with verilator to see the check fail.
