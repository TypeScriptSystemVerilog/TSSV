# TSSV coding style

Guidelines for the TypeScript that generates a TSSV module's SystemVerilog: parameters and
width calculation, module structure, builder choice, naming and tests. Not written yet; see
[#58](https://github.com/TypeScriptSystemVerilog/TSSV/issues/58).

Until then, the builder rules in the SV guide ([`../sv-style/sv-coding-style.md`](../sv-style/sv-coding-style.md))
stand in for it: COMB-7, COMB-8, SEQ-3, LATCH-1, RST-1, NAME-1 to NAME-3 and WIDTH-8.
